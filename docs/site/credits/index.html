Sherpa-ONNX

The core engine powering VoxSherpa's offline capabilities.

VoxSherpa is powered by Sherpa-ONNX, an excellent open-source project that makes fast, offline speech processing possible on Android and other edge devices. We are happy to build on the work of its contributors.

Visit Official GitHub
